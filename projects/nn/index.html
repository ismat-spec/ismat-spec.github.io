What am I looking at?

The network takes a point's (x, y) position and predicts which class it belongs to. Training runs gradient descent: for every batch of points the code computes the prediction error, then backpropagates it — applying the chain rule layer by layer to find how much each weight contributed — and nudges every weight downhill. The background heatmap re-renders as the weights change, so you literally watch the model's "opinion" of the plane take shape. The two-spirals set is the classic stress test: with raw (x, y) inputs even a deep network crawls, because the boundary it must draw is extremely tangled. Flip Features to the engineered set — the same network now also sees x², y², xy and two sine waves of the inputs, and the spiral falls in seconds. That is the oldest lesson in machine learning: a better representation of the data beats a bigger model.
