How the algorithms differ

Dijkstra expands outward in order of cheapest total cost from the start — it is guaranteed optimal, but explores in every direction. A* adds a heuristic (here the Manhattan distance to the target) so it pushes toward the goal first while staying optimal — usually visiting far fewer cells. Breadth-First Search treats every step as equal, so it finds the fewest-steps path but ignores terrain cost — watch it plough straight through sand. Greedy Best-First chases the heuristic alone: very fast, but the path it finds can be noticeably longer. Try each on the same maze and compare the visited count and path cost.
